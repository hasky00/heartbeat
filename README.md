# HEARTBEAT Gaza

An independent concept in the prototyping stage for a simple, durable and
affordable family-home pilot for displaced families in Gaza.

HEARTBEAT Gaza is not a registered charity or humanitarian organization and is
not currently soliciting donations. Organizations named in the project
documents are prospective outreach recipients only and do not currently
endorse, fund or partner with the project.
